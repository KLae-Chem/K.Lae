# KLae — Organic Chemistry Teacher Portfolio

A personal academic portfolio website for **KLae**, an Organic Chemistry Teacher and chemistry educator. The portfolio presents teaching interests, educational philosophy, curriculum development interests, and work related to innovative chemistry education and digital learning.

The website is designed as a simple, elegant, academic-style portfolio using **only HTML and CSS**, with no JavaScript or external frameworks.

## About

I am an Organic Chemistry Teacher passionate about helping students understand the principles, reactions, and applications of organic chemistry. My teaching approach focuses on connecting fundamental concepts with practical examples, laboratory experiences, and real-world applications. I aim to create an engaging and supportive learning environment where students can develop strong chemical knowledge, analytical thinking, problem-solving skills, and confidence in applying chemistry to scientific challenges.

Beyond classroom teaching, I am interested in curriculum development, innovative chemistry education, and the integration of digital technologies into learning. I believe that effective chemistry education should not only develop theoretical understanding but also cultivate laboratory competence, scientific communication, creativity, ethical responsibility, and lifelong learning. My goal is to inspire students to explore chemistry deeply and apply their knowledge to research, industry, education, and sustainable development.

## Technology

This project intentionally uses a lightweight technology stack:

* **HTML5** — Website structure and content
* **CSS3** — Layout, typography, animations, and visual design
* **Edu QLD Beginner** — Primary typeface
* **No JavaScript**
* **No CSS framework**
* **No JavaScript framework**

The website can therefore be hosted easily on static hosting services such as GitHub Pages.
